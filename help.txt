  Key Features

  - High-contrast black/green UI - readable in sunlight
  - Live gauges - RPM, MAP, Fuel Flow, Oil Temp/Press, Volts, EGT 1-4, CHT 1-4
  - CHT color warnings - yellow >380°F, red >400°F
  - Start/Stop buttons - control capture from iPad
  - File download - download captures directly to iPad
  - Auto-timestamp - files named with GPS time when stopped
  - No overwrite - never overwrites existing files
  - Uses cron - works with overlay enabled

  To Install

  # Copy to Pi
  scp -r ~/stratux/capture_v2 pi@192.168.1.252:/home/pi/

  # SSH to Pi
  ssh pi@192.168.1.252

  # Install
  cd /home/pi/capture_v2
  ./install.sh

  # Start now
  /home/pi/start_monitor.sh

  Access

  Open on iPad: http://stratux.local:8080

  Both Stratux (port 80) and Engine Monitor (port 8080) run simultaneously.
